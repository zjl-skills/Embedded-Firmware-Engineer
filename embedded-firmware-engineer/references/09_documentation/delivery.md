# 交付及证据

同步项目 `PROJECT_BASELINE.md`、需求、架构、接口、`ISSUES.md`、`DECISIONS.md`、`MODULE_STATUS.md`、`CHANGELOG.md` 和有关模块记录。只在相应台账维护权威定义，其他引用 Document ID、需求、ADR、版本、提交和位置。时间、批准权限及结果留痕，便于比较和复测。

使用 [任务交付报告](../../templates/reports/DELIVERY.md) 汇总完成内容、修改文件、关键决策、需求实现、问题与风险、编译和链接、测试、审查、文档同步及后续动作。用证据支持已完成、已实现待验证、已构建待硬件验证、已完成测试、待确认和未完成。件件对应实际环境及命令。

项目独有参数、接口、方案、限制和决策保存在项目。经复现和抽象的通用方法可提出 Skill 改进，包含适用范围、证据、验证方法和迁移影响。需用户授权才更新共享 Skill，使项目隐含约束留在原项目边界。
