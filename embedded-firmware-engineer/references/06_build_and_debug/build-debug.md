# 工具链与调试

## 构建

识别实际目标、配置、依赖及历史可用命令。对 Keil MDK 核对 `.uvproj(x)` 目标和 ARMClang/旧 ARMCC 选择，对 IAR EWARM 核对 `.ewp`、`IarBuild` 及许可版本。对 GCC、`arm-none-eabi-gcc`、CMake、Make、STM32CubeIDE、MCUXpresso 和其他 IDE 追踪活动 preset/target、toolchain、生成脚本及产物路径。PATH 存在性只说明命令可定位。执行项目命令前检查来源、写入、下载和设备副作用。

优先使用实际构建入口，保留编译器版本、宏、包含路径、ABI、优化、链接库、链接文件、启动配置、map/size 和日志。在原任务授权之外，先协调编译器、启动、链接、内存分区、关键宏和工程结构改动。失败要定位错误属于配置、编译、链接还是工具/许可。分别记录已有目标、宿主模拟和实板结果。

## 故障定位

复现 → 收集证据 → 根因 → 方案 → 最小修复 → 复测及回归 → 记录。保留提交、板版次、镜像、环境、频次及可观察信号。若缺复现，给出最小日志或实验来区分候选原因。

| 现象 | 证据与定位 |
| --- | --- |
| HardFault、BusFault、MemManage | 核对架构能力和有效位，保存异常现场、堆栈、返回地址、对应 ELF/map/反汇编、MPU 与时序条件。 |
| 栈溢出、越界、野指针、泄漏 | 栈高水位或保护、缓冲区所有权、边界、分配释放路径，缩小最早破坏点。 |
| 死锁、竞态、IRQ、DMA | 记录任务/ISR/优先级和锁序，核对缓冲区生命周期、缓存、IRQ 清除方式、重入和停机流程。 |
| 丢包、时序、初始化 | 捕获可关联时间戳的总线、波形、错误码和状态，核对时钟、上电恢复、拥塞及超时。 |
| 功耗异常 | 记录供电、测量设备、负载、唤醒源、调试连接、时钟域和工作/休眠比。 |

任何额外延时、屏蔽中断或错误降级都有技术依据、影响边界和回归验证。烧录、擦写、上电与刻意故障注入依硬件条件、用户授权和实际工具执行。
