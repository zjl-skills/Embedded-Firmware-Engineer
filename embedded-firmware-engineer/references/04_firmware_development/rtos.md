# RTOS 与 OS 适配

结合时限、并发、维护成本、内存和平台支持，比较继续裸机与采用 FreeRTOS、RT-Thread 或其他适用内核。核对官方文档、实际内核版本、架构 port、编译器、调度配置、系统节拍及 tickless 配置。保留主机 stub 作为可测试边界。

## 设计任务与同步

| 设计项 | 交付、验证要点 |
| --- | --- |
| 任务和优先级 | 任务所有者、栈和优先级、周期/最坏时间、阻塞上限、优先级反转及测量方法 |
| 队列、信号量、互斥锁和事件组 | 生产消费语义、容量、所有权、拷贝或引用、超时、丢弃策略、锁级和退出次序 |
| 软件定时器 | 回调上下文、执行时限、重入、停止和资源回收顺序 |
| ISR 到任务 | 仅使用该内核及版本允许的 ISR API，核对可调用优先级、抢占及唤醒行为 |
| 临界区及竞态 | 锁粒度、共享数据一致性、抢占和中断屏蔽时长，设计死锁和过载测试 |

OS 适配层集中时间转换、同步原语、任务生命周期及 ISR 对应操作。定义时间单位、无期限等待、返回码、错误传递、删除和唤醒语义。HAL 回调、DMA 完成与应用事件在契约规定的位置转换。线程安全层级和 ISR 可调用方法在接口声明处标注。

迁移时用旧工程建立功能与时延基线，保留单调时间和溢出语义，分阶段替换调度。核对所有阻塞 I/O 能否使高优先级任务饥饿。测试队列满、超时、并发关闭、内存不足、异常中断及长期负载，测量栈高水位、中断/线程响应和 CPU 占用。详见 [质量验证](../07_quality_assurance/verification.md)。
