# 驱动、裸机与编码规范

## 驱动方案

先确认器件和修订、外设实例、引脚、电气、时钟、IRQ/DMA 和 SDK 来源，再选择寄存器、LL/HAL 或现有驱动接口。保持公开 API 的生命周期一致，明确初始化与反初始化、读写、参数、超时、异步完成、取消、恢复和幂等条件。中断只做有界操作，将耗时工作交给可调度上下文。

| 类别 | 设计或审查重点 |
| --- | --- |
| GPIO / EXTI | 上电安全态、极性、抖动、边沿、共享中断清除语义 |
| UART / SPI / I2C / CAN | 总线角色、速率、数据宽度、缓冲区及溢出、仲裁/错误恢复、时限和重试策略 |
| USB | 角色、端点、描述符依据、时钟、枚举及拔插恢复 |
| ADC / DAC / PWM / Timer | 触发、采样窗口、校准、基准电压、计数溢出、更新边界和输出安全态 |
| DMA | 请求映射、缓冲区生命周期、对齐、缓存一致性、错误与取消、IRQ 和重启 |
| RTC / Watchdog | 时钟与漂移、断电保留、喂狗条件、复位原因和回绕 |
| Flash / 外部存储器 | 对齐、页/扇区、擦写耐久、断电一致性、ECC、延迟及执行限制 |

EEPROM、NOR/NAND Flash、RTC、温湿度/压力传感器、IMU、显示屏、电机驱动、电源管理与通信模块按具体器件官方手册实现。核对 ID、地址位格式、SPI 模式、上电/复位序列、读写约束、状态清除、异常响应及总线恢复。共享总线集中仲裁，避免设备间隐含时序依赖。

## 裸机调度

使用有界主循环，分离节拍、事件入队、周期任务和非阻塞状态机。定时运算校验计数宽度、回绕和允许间隔。明确每个状态的超时、重试或退出，评估轮询周期、最坏中断延迟及 CPU 占用。中断与主循环共享数据用明确的原子访问、临界区或单生产者队列，校验整组状态的一致性。缓冲区指定长度、并发、所有权和满时策略。低功耗唤醒复核时钟恢复、节拍连续性和外设状态。

## 项目编码规则

遵循工程的 C/C++ 方言、公开 API、可见性、编码和格式规范。默认采用 C，允许项目选用 C++。参考 MISRA C/C++ 的边界、类型、确定性和可维护性原则。声称标准合规需要项目选择规则版本、检查工具、偏离流程及证据。

- 头文件可独立包含，依赖明确。限制全局可写状态，集中定义错误码及调用方的响应规则。
- 默认静态内存，动态分配记录失败路径、碎片、并发和最坏时延。检查输入、长度、溢出、符号转换、空指针和数组边界。
- 核对 ISR、线程、DMA 和硬件寄存器并发。`volatile` 管理可见读写，临界区、原子性和内存顺序按具体架构、编译器及所有者约定验证。
- 注释说明非显然的硬件约束、并发和时序假设、证据位置。默认中文注释，项目或用户指定语言优先。标识符按现有英文风格。
- 每项实时、RAM/Flash、CPU、栈、低功耗或耐久目标写出预算、测量条件和回归方法。关键分配优先用 map、栈测量、波形和实际负载证据核对。
